# Paso 0 — Conceptos previos

**Tag de referencia:** `paso-0-conceptos`

## Objetivo

Asegurar que todos los participantes manejan terminal, YAML y el concepto de pipeline antes de tocar Git o Docker.

## Qué hacer

1. Diagnóstico rápido en voz alta: ¿quién ya usa terminal cómodamente? Ajusta el ritmo según la respuesta.
2. Revisar [`01-conceptos-previos/01-terminal.md`](../01-conceptos-previos/01-terminal.md) — práctica de 2 minutos con `pwd`, `ls`, `cd`
3. Revisar [`01-conceptos-previos/02-yaml.md`](../01-conceptos-previos/02-yaml.md) — estructura básica, sin ver el `ci.yml` real todavía
4. Revisar [`01-conceptos-previos/03-que-es-un-pipeline.md`](../01-conceptos-previos/03-que-es-un-pipeline.md) — concepto, sin código

## Cómo verifico que funcionó

- Todos los participantes pueden abrir una terminal y navegar a la carpeta del proyecto
- Pueden identificar visualmente un error de indentación en un YAML de ejemplo
- Pueden explicar con sus palabras la diferencia entre CI y CD

## Reto avanzado

Para quienes ya dominan esto: pueden adelantarse a leer el `.github/workflows/ci.yml` real y tratar de predecir qué hace cada línea, antes de que se explique en el paso 3.
